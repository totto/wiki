# Ventures

I run several companies at once, and they are not a scatter — they are the same thesis approached from different angles. AI changes how software gets built ([Skill-Driven Development](/topics/skill-driven-development/)); that only pays off on top of real [knowledge infrastructure](/knowledge-infrastructure/); and once agents start making consequential decisions, the decisions have to be [defendable](/topics/defendable-agents/). Each venture below is one bet on part of that arc.
